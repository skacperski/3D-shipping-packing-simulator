# Sowa Liczba – interaktywny korepetytor (ułamki dziesiętne i rachunki w pamięci)

Otwórz `index.html` w przeglądarce (działa offline, bez instalacji). Postępy zapisują się w przeglądarce.

Zawartość: 7 rozdziałów / 63 lekcje – wszystkie zadania ze stron 10–23 podręcznika
(liczby naturalne w pamięci, ułamki dziesiętne w pamięci, działania pisemne, zadania tekstowe, super zagadki).
Każde zadanie: krótkie wyjaśnienie → przykład → ćwiczenia z podpowiedziami → pytania sprawdzające zrozumienie → gwiazdki.
